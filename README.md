## 🚀 How to Run & Preview Locally

1. **Option A (Direct Double-Click)**:
   - Navigate to `d:\Madhesh_Portfolio\` in Windows File Explorer.
   - Double-click `index.html` to open it in Brave / Chrome / Edge.

2. **Option B (VS Code Live Server)**:
   - Open the `Madhesh_Portfolio` folder in VS Code.
   - Click **Go Live** (or install the Live Server extension).

## 🌐 How to Deploy Online (Free in 2 Minutes)

### Method 1: GitHub Pages (Recommended)
1. Create a new GitHub repository named `portfolio` on your GitHub account (`GitHub-MadheshN-eng`).
2. Upload `index.html`, `style.css`, and `app.js` to the repository.
3. Go to **Settings** > **Pages** > Select `main` branch > Click **Save**.
4. Your site will be live at `https://madheshn-eng.github.io/portfolio/`.

### Method 2: Vercel / Netlify
1. Drag and drop the `Madhesh_Portfolio` folder directly onto [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
2. It will deploy instantly and provide a custom `.vercel.app` or `.netlify.app` domain link!
